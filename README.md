# Loa Báo Tiền

App Android tự đọc to số tiền khi nhóm Telegram SePay báo "Tiền vào".

## Build APK bằng GitHub
1. Tạo repo mới trên GitHub, đẩy toàn bộ thư mục này lên nhánh `main`.
2. Vào tab **Actions** > chạy **Build APK** (tự chạy khi push).
3. Build xong, tải file `LoaBaoTien-debug-apk` ở mục **Artifacts**, giải nén ra `app-debug.apk`.
4. Chép vào điện thoại, cài (cho phép cài từ nguồn ngoài).

## Dùng
1. Mở app > **Cấp quyền đọc thông báo** > bật cho Loa Báo Tiền.
2. Bấm **Nghe thử** để kiểm tra giọng tiếng Việt.
3. Telegram: bật thông báo nhóm SePay, bật xem trước nội dung tin.
